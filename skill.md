# Frontend Design Skill

## Core Principles
- Avoid generic AI-generated design clichés (such as excessive floating gradient cards, identical rounded card kits for everything, heavy drop shadows, or generic all-caps eyebrow labels over every heading).
- Motion should be purposeful and natural (answering a user's action like opening, expanding, or confirming) rather than decorative or distracting.
- Pay close attention to typography, hierarchy, and layout structure. Ensure clean, readable layouts without clutter.

## Process: Plan, Review against the brief, build, critique
1. Brainstorm a clean, structured design plan based on the core brief.
2. Define a consistent color palette (4-6 named hex values), typography roles, and clean layout geometry.
3. Ensure high contrast, proper spacing, and maintain absolute design consistency across desktop and mobile viewports.
4. Keep interactions functional, clean, and tightly integrated with Tailwind CSS classes.
